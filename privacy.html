🌿 줍깅 땅따먹기

개인정보 안내

줍깅 땅따먹기는 주운 자리를 지도에 남기는 가벼운 게임이에요. 게임에 필요한 정보만 받고, 그 밖의 것은 받지 않아요.

받는 정보

Google로 로그인하면

  • Google 계정의 이름과 이메일 주소 (땅 주인 표시와 계정 구분에 사용)
  • 프로필 사진은 받지 않아요.
  • 비밀번호는 전혀 받지 않습니다. 로그인은 Google이 처리하고, 이 앱은 결과만 받아요.

직접 만든 기록

  • 닉네임 — 지도에 표시되는 이름 (기본값은 Google 이름, 언제든 변경 가능)
  • 인증 사진 — 주운 쓰레기 사진. 올리기 전에 기기에서 가로세로 720px JPEG로 줄여서 저장해요.
  • 땅 정보 — 점령한 격자 칸의 좌표, 한 줄 메모, 점령 시각, 몇 번 인증했는지

위치 정보

‘내 위치로’ 버튼을 눌렀을 때만 브라우저가 현재 위치를 알려줘요. 이 위치는 지도 화면을 옮기는 데만 쓰고 서버에 저장하지 않습니다. 저장되는 것은 내가 직접 고르거나 인증한 땅 칸의 좌표뿐이에요.

어디에 저장되나요

  • Supabase — 땅·인증 기록·계정 정보가 저장되는 데이터베이스 (로그인 세션 토큰도 이 브라우저에 보관)
  • 이 브라우저(localStorage) — 로그인 세션, 닉네임
  • 인증 기록(닉네임·사진·메모·시각)은 게임 특성상 다른 참가자에게도 보여요. 개인정보가 담긴 사진은 올리지 마세요.

함께 쓰는 서비스

  • Google 로그인 — 계정 인증
  • Supabase — 데이터 저장·인증 서버
  • GitHub Pages — 웹페이지 호스팅
  • OpenStreetMap — 지도 타일

광고·분석(트래커) 도구는 넣지 않았어요. 받은 정보를 팔거나 다른 목적으로 넘기지 않습니다.
